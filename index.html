Everything below is implemented and working in this build. Advanced research modules are scaffolded with a clear roadmap.

🧠

Biophysical neuron models

Leaky integrate-and-fire, Izhikevich, and adaptive-exponential (AdEx) neurons with conductance-based synapses and conduction delays.

Working
🌐

GPU-instanced 3D view

Watch thousands of neurons spike in real time with Three.js instanced rendering, orbit controls, and multiple spatial layouts.

Working
📊

Live analytics

Population firing rate, synchrony index, CV(ISI), and autocorrelation-based oscillation detection with an automatic regime classifier.

Working
🔬

Synaptic plasticity

Pair-based spike-timing-dependent plasticity (STDP) on excitatory synapses you can toggle live and watch reorganize.

Working
💡

Closed-loop optogenetics

Inject virtual light through ChR2, ChrimsonR, eNpHR or ArchT opsins with realistic saturating activation curves.

Working
🤖

AI Copilot + voice

Control experiments in plain English — “produce 40 Hz gamma”, “increase inhibition” — fully offline, with optional voice input.

Working
🐍

Reproducible code export

Export the current network as a runnable Brian2 Python script, a JSON spec, spike-train CSV, and metrics CSV.

Working
🖍️

Connectome toolbox

Graph-theory metrics, degree distributions, hub-targeted lesion studies, and mutual-information between spike trains.

Working

Colorblind-safe palettes (protan/deutan/tritan), keyboard shortcuts, voice control, and responsive layout.
